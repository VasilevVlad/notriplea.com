# notriplea.com

Сайт NoTriple-A Games: политики конфиденциальности игр. Хостинг — GitHub Pages, домен notriplea.com (файл `CNAME`).

- `index.html` — главная, список игр.
- `<игра>/privacy/` — политика EN, `<игра>/privacy/ru/` — RU. Страницы генерирует `python3 tools/build.py` из `tools/games.json` (что стоит в каждой игре) и текста в `build.py` — руками HTML не править.
- `style.css` — общий стиль.

Правка политики: поменять текст и дату вступления в силу, закоммитить и запушить — сайт обновится сам через 1–2 минуты.
